Small chips next to the username (for example 🤖 97% · 🏛 2%), on matched and unmatched tweets alike. Tags and highlights still follow the threshold.
Jev is a System One model: it cannot write text, it only answers typed questions with calibrated probabilities, in about 150 to 300 ms and for roughly $0.00002 per tweet. Your LLM still writes each topic's criteria (patterns, emoji, and a one-sentence decision rule); Jev then returns a probability for every topic on every tweet. Tweets go out in bulk, 8 per call with several calls in flight, and only uncertain scores get a second single-tweet opinion. If Jev is unreachable the LLM takes over.
